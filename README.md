# 房东小日子

在深圳当房东的中文网页经营小游戏：从 8 套房子、2 位租客起步，通过出租、维护、购房和改善社区逐步扩张，最终持有 **1200 套房产全部出租**、每月获得 **¥1,600,000 租金**并连续保持 **6 个月**，完成经营挑战。

单人、回合制（一个回合代表一个月）、纯前端运行，无需后端、无需账号，数据保存在浏览器本地。

## 快速开始

```bash
# 安装依赖
npm install

npm run dev

npm run preview
```

## 玩法与规则

### 每月循环

```text
查看经营情况 → 处理租客事件 → 购房/翻新/设置招租与管理方案
→ 查看月末预测 → 点击"结束本月" → 收租动效 → 经营月报 → 下个月
```

- 购房、翻新、配套升级**立即扣款**；新购房产当月可参与招租。
- 只有点击「结束本月」才推进时间；月末预测与正式结算**共用同一个结算模型**。
- 不开放出售房产。

### 房型（固定基础租金与最大供应）

| 房型 | 最大数量 | 月租金 | 购买价 | 解锁 |
|---|---:|---:|---:|---|
| 基础公寓 | 600 套 | ¥1,000 | ¥6,000 | 开局 |
| 舒适公寓 | 400 套 | ¥1,500 | ¥9,000 | 持有 20 套 |
| 家庭公寓 | 200 套 | ¥2,000 | ¥12,000 | 持有 100 套 |

满租收入：600×1,000 + 400×1,500 + 200×2,000 = **¥1,600,000/月**。

### 招租

- 每月基础候选数 = 2 + ceil(持有房产 × 3%)。
- 招租方案：自然招租（免费）/ 社区推广（房产×¥20，候选 +2%）/ 城市推广（房产×¥50，候选 +5%）。
- 转化率 = clamp(60% + 满意度×0.4% + 配套等级×3%, 60%, 100%)；每月可签约 = floor(候选 × 转化率)。
- 手动签约消耗本月候选容量，重复点击不会刷新候选池。
- 退租率 = clamp(2% + max(0, 70−满意度)×0.1% − 管家等级×0.3%, 0.5%, 5%)；退租数 = floor(月初已出租 × 退租率)。
- 「提前续租沟通」使退租数减少 floor(原数量×30%)，费用 = 月初已出租 × ¥10。
- 月末先退租，再由自动补租（需管家 Lv.1+）用剩余候选补空房。
- 分配优先级可切换：优先基础 / 优先高租金（结果确定）。

### 翻新与维护

- 翻新 0→1 级 ¥800/套、1→2 级 ¥1,200/套，分别使该组维护支出降低 10%、20%（按数量加权），不增加租金。
- 维护状态每月自然下降 6 点；维修策略：节省（¥30/套，+2）/ 常规（¥60/套，+6）/ 精细（¥100/套，+10）/ 暂停（免费）。
- 维护 < 60 时，当月满意度下降 ceil((60−维护)/10)。

### 管家与社区配套

| 系统 | 升级费 | 月费 | 效果 |
|---|---|---|---|
| 管家 0—3 级 | ¥10,000×目标等级 | 房产×等级×¥10 | 降退租率，Lv.1 解锁自动补租 |
| 配套 0—3 级 | ¥15,000×目标等级 | 房产×等级×¥5 | 提高转化率，解锁场景装饰 |

### 困难保护

- 预测月末资金不足时「结束本月」不可执行，并显示缺口。
- 提供「调整为基础运营」（自然招租+节省维护+关闭续租）与「暂停全部服务」快捷操作；暂停服务不收费也不提供效果。
- 资金永不为负，无永久失败结局。

### 胜利

同一次月末结算同时满足：房产 1200、出租 1200、月租金 ¥1,600,000，连续 6 次后胜利。胜利后展示经营成绩，可继续经营。

## 技术栈

React 18 + TypeScript + Vite 6 · Zustand（状态管理）· Motion（界面动效）· Vitest（规则测试）· Playwright（浏览器验收）

## 项目结构

```text
src/
  game/            核心经营纯函数（预测与结算共用）
    types.ts constants.ts economy.ts recruitment.ts
    settlement.ts events.ts progression.ts save.ts simulator.ts rng.ts
  data/            角色、事件、故事链、Emoji 素材清单
  store/           Zustand 状态与全部操作
  components/      界面组件与六个页面
  styles/          全局样式（视觉规范）
scripts/simulate.ts  无界面通关模拟
tests/             规则测试 + e2e 浏览器验收
public/emoji/      本地动画 Emoji 素材（Noto Emoji Animation）
```

## 存档

- 购房、升级、事件选择、月末结算后自动保存到浏览器 localStorage。
- 设置页支持导出 JSON 存档、粘贴文本或选择文件导入；导入时校验结构、金额、上限与出租数，损坏存档不会导致页面崩溃。
- 保留最近一次有效存档备份；重新开始与导入覆盖均需确认。

## 已知限制

- 动态 Emoji 素材为 512px 动画 WebP（约 4.7MB，共 14 个），首次加载按需取用；加载失败自动降级为静态 Emoji + CSS 动画。详见 ASSET_LICENSES.md。
- 音效为 WebAudio 合成音，默认关闭。
- 购房价格等为虚构游戏数值，不模拟现实房价。
